## 一、需求从哪来

立项卡（`docs/立项卡.md`）里，这个软件只为解决三件事：

1. **课前 12 小时 / 2 小时提醒**：别错过课，也别错过换教室。
2. **作业提醒系统**：记下作业和截止时间，临期标红。
3. 给自己和宿舍四个人用，手机上能打开。

约束也很清楚：**大一新生，不写后端、不买服务器、不装 App**。所以"能跑在浏览器里"是硬条件。

## 三、关键技术决策

### 1. 为什么用 Vite + React，而不是一个 index.html 写原生 JS

第一版其实写过一个纯 JS 的（`E:\code\timetable`，还在），到"点格子 → 弹层 → 存本地 → 重渲染"这一步就开始手写 `innerHTML` 拼接，代码 300 行以后改一处怕三处。

React 解决的就一件事：**数据变了，界面自己跟着变**。课表的状态其实只有三个对象（课、作息、作业），组件化之后 `PeriodRow` 只关心"我这一格有没有课"。

### 2. 数据结构：为什么键名是 `'2-1'` 这种字符串

```js
courses = { '2-1': { name: '大学生心理健康教育', place: '弘远楼B0412', color: 'c1' } }
//            ↑星期几-大节号：周二第 1 大节
```

用二维数组也行，但 localStorage 里数组套数组、删一个格子留个 `null`，排序和遍历都别扭。扁平字典的增删改都是 `obj[key] = x` / `delete obj[key]`，7×5=35 个格子完全够用。

### 3. 为什么是「5 个大节」而不是完整 12 小节

学校显示的是 12 个小节，但**课表上真正占用的只有 5 个大节**（每节 2 小节）。如果按 12 小节画，屏幕上永远有 4-5 行空格子，翻半天才找到课。

所以界面按大节排，同时在时间列标出「1-2 节」——小节号在格子里能看见，但不用为空格子付版面。

### 4. 真实课表怎么来的：截图逐格解析（这段最费劲）

用户只给了一张课表 App 的截图，没有导出的 Excel。做法：

1. 先找出表格的**5 条竖线**（灰度投影找列边界），得到「星期几」的 x 区间；
2. 再按大节的 y 区间切出每一格，**逐格裁图 OCR**；
3. 手工核对：11 门课、房号、[1] 这种周次标记。

为什么不整张图一次 OCR：整图识别回来的是**线性文字**，丢掉了"第几行第几列"，等于要人肉重新对位。按格切图以后，每张图只需要回答"这格里写了什么"，错位风险直接归零。

代价：三处「高等数学(1)机电」的房号在原图里就被截断成 `弘远楼B0…`，代码里原样存着，界面标「待补」——**不猜**。

### 5. 提醒为什么不做网页弹窗

立项卡要求"课前 12 小时 / 2 小时提醒"。网页有个绕不过去的限制：

> **页面关掉以后，网页什么都不会响。**（浏览器不允许网站在关闭状态下自己弹通知；Service Worker 的 push 需要后端推消息）

所以提醒只有两条路：装成 PWA 保持后台（不保证），或者**交给系统日历**。选了后者：

- 导出 `.ics`，每门课一条 `RRULE:FREQ=WEEKLY` 的日程，挂两个 `VALARM`（`-PT12H`、`-PT2H`）；
- 导进手机日历后，锁屏也会响，网页开不开都无关；
- 作业同理（截止前 12h / 2h），已完成的作业不导出。

`src/ics.js` 里两个细节是规范要求、不是洁癖：**每行不超过 75 字节要折行**（续行以空格开头）、**逗号分号要转义**（不然课程名里有个逗号，日历就解析错）。

### 6. 双休与「待补」

- 周六周日没课 → 不画 5 个空格子，显示一张「周末双休」卡（少 10 个空格的视觉噪音）。
- 房号被截图截断 → 不编造，标「待补」，点开补完就消失。**未知就显示未知**，比填一个错的强。

## 四、怎么证明它能用（验证方式）

每改完一版都跑三件事，任何一步不通过就不算完成：

1. **构建**：`node node_modules/vite/bin/vite.js build` —— 能过说明语法/引用没问题。
2. **真浏览器里点**：Playwright 驱动 Edge（headless），模拟手机 390×1900 视口。
   - DOM 断言：`.slot` 数量、`.hwitem` 数量与 class、`.rest` 是否存在；
   - 交互断言：点「+ 加一项」→ 填表 → 保存 → 列表真的多一条；点圆圈 → 那条真的移到最底；
   - 下载断言：点「导出日历」→ 接住 `download` 事件 → 读文件内容数 `VEVENT`/`VALARM`/`RRULE`。
3. **看截图**：DOM 断言过了不代表好看，每次都亲眼看一遍渲染结果。

实测记录（都是真实跑出来的数字）：

| 检查项 | 结果 |
| --- | --- |
| 周五（10/30）有课数 | 5/5 |
| 周六 / 周日 | 0 个格子 + 「周末双休」卡 + 计数显示「双休」 |
| 大节小节号 | `1-2 节` … `9-10 节` |
| 作业排序 | 未完成按截止时间升序在前，已完成沉底 |
| 作业标红 | 剩 4 小时 → `hwitem--urgent`；已过期 → `hwitem--late` |
| 点按钮导出 | 文件名 `课表-作业提醒.ics`，11 VEVENT / 22 VALARM / 11 RRULE，正文正常结束 |
| 单独测 `.ics` 生成（带 1 条作业） | 12 VEVENT / 24 VALARM / 最长行 59 字节（未超 75）/ 逗号已转义 / 已完成作业未导出 |

## 五、踩坑记录（下次别再摔）

1. **`Date` 会偷偷改月份**：`new Date(2026, 9, 31)` 是 10 月 31 日（月份从 0 开始）。所以统一走 `addDays()` 包装，不手写 `getDate() + 1`。
2. **`getDay()` 是 0=周日**，而课表要「周一=1」，中间有个 `isoWeekday()` 换算，别混用。
3. **localStorage 里只有字符串**：存 `JSON.stringify`，读必须 `try/catch`（用户可能手改坏），坏数据回落到默认值而不是白屏。
4. **装 Git 用 winget 便携版**：`winget install Git.Git` 装到 `AppData\Local\Programs\Git`，**PATH 要重开终端才生效**。
5. **别用 PowerShell 改源码文件**：`Get-Content -Raw | Set-Content` 会把 UTF-8 中文写坏（变成乱码、引号还可能炸掉语法）。改代码用编辑器/写文件工具，别走 shell 字符串替换。
6. **`npm` 不一定在 PATH 上**：这台机器的 npm 挂在 `E:\Deepseek harness\npm.cmd`，或者干脆直接调 `node node_modules/vite/bin/vite.js`，少一层依赖。
7. **Playwright 的 `playwright-core` 要装在项目里**（`node_modules`），放临时目录会 `ERR_MODULE_NOT_FOUND`；浏览器用系统 Edge，不必下载 Chromium。
8. **日期条不是按星期索引**：页面顶部是「今天 ±5 天」，今天在 index 5 而不是 index 1，自动化里别按固定下标点"周六"。
